## Key Points to Emphasize

### Economy System
- **New users**: 50 tokens + 5 crowns
- **Prediction cost**: 1 token
- **Win rewards**: 3 tokens + 1 crown
- **Exact score bonus**: +1 crown
- **Daily login**: 3 tokens
- **7-day streak**: 1 crown bonus
- **Draw entry**: 1 crown

### User Experience Features
- **Duplicate prevention**: Can't predict same game twice
- **Score validation**: Predicted scores must match selected winner
- **Two-step confirmation**: Prize draw entries require two clicks
- **Real-time updates**: Balances update immediately
- **Visual feedback**: Clear success/error messages

### Navigation Flow
1. Login → Home
2. Home → Games → Prediction Modal
3. Prediction Modal → Submit → Back to Games
4. Games → Weekly Draw
5. Weekly Draw → Enter → Confirmation
